# Baby Owl Hollow — Design Document

A single-page, screensaver-style scene in the spirit of Sierra's *Johnny Castaway*:
a warm, self-running world with a recurring cast of characters, gentle ambient
motion, and small stories that play out on their own. Bright, cute, storybook colors.

Open `index.html` directly from disk (`file://`) or serve the folder — no build
step, no assets, no network needed.

## Why this implementation

- **SVG + one `requestAnimationFrame` loop.** Crisp vector art at any window size,
  one `viewBox` (1600x900) with `preserveAspectRatio="xMidYMid slice"` so it fills
  the screen like a real screensaver.
- **Classic scripts, not ES modules.** ES modules are blocked by CORS when opened
  via `file://`; plain `<script src>` tags work everywhere. Files share globals.
- **Everything generated by JS.** The owls, flowers, tufts, butterflies etc. are
  built programmatically so poses/animations are just transform updates.
- **No external assets, fonts, or libraries.** System font stack only.

## File layout

| File | Responsibility |
|---|---|
| `index.html` | SVG stage, gradient defs, UI overlay (buttons, hint), script tags |
| `css/style.css` | Fullscreen stage, UI pill styling, cursor-idle behavior |
| `js/scene.js` | Shared helpers (`svgEl`, `cubic`, easing, `mixHex`), background: sky, sun, moon, stars, clouds, hills, ground, tree, pond, grass details, butterflies, leaves, sparkles, fireflies, rain/snow/rainbow; atmosphere clock (day/night, weather, seasons) |
| `js/owls.js` | `Owl` class: body/wings/eyes/beak/feet built from SVG shapes; per-frame update (blink, gaze tracking, flap, hop, bob, sleepy lids); speech bubbles |
| `js/stories.js` | Story context `S` (wait/skip, fly paths, splash, fish, zzz, hearts) + the 3 stories as async scripts |
| `js/main.js` | Boot, rAF loop, mouse/keyboard/click input, story scheduler, WebAudio sound, fullscreen |

SVG layer order (bottom → top): `bg` → `mid` (pond, tree) → `fg` (grass details)
→ `owls` → `critters` → `fx` (bubbles, splashes, zzz, rain/snow, huddle leaf)
→ `tint` (day/night overlay) → vignette. `critters`, `fx` and `tint` are click-through.

## The cast

- **Olive** (parent, brown, scale 1.05) — perched on the big branch at (1120, 393).
- **Pip** (baby, light tan, scale 0.62) — on the branch at (950, 419).
- **Puff** (baby, soft grey-blue, scale 0.60) — on a red mushroom at (800, 682).

Owls are built from layered shapes (body, scalloped belly, ear tufts, facial discs,
big amber-irised eyes with movable pupils, blush, beak, side wings, feet) so
animation = transform updates:
wings rotate around the shoulder, eyes squash for blinks and droop when sleepy,
pupils track the mouse, the whole body bobs (breathing) and hops.

## The three stories (rotate automatically, ~12–18 s idle gap)

1. **First Flight** — Pip hops, flaps excitedly, glides from the branch to a stub
   near the trunk while Olive watches, then flies back. Proud hoots, happy wiggles.
2. **Fishing Lesson** — Puff watches from the mushroom as Olive flies to the pond,
   waits by the water, catches a fish (splash + arc into beak), flies back for a
   snack. Then Puff tries, gets a big splash and no fish, and Olive cheers anyway.
3. **Nap Time** — Olive yawns and "tells a story", both babies' eyes droop, `z`
   floats up, a butterfly lands on Olive's head. Gentle wake-up stretch.

Stories are async functions using `await S.wait(ms)`; **Space** (or clicking the
background) skips the current story — waits reject with a `SKIP` sentinel and the
runner restores everyone to their home pose. Keys **1/2/3** jump to a story.

## Ambient life (always running)

Drifting clouds, rotating sun rays, birds, swaying grass/flowers/reeds, pond
ripples, Lissajous-flying butterflies, occasional falling leaves, floating
sparkles, random idle emotes (hops, wiggles, wing stretches, blinks).

## Atmosphere (day/night, weather, seasons)

The world lives on a clock: one full day/night cycle every 3 minutes
(`Scene.dayMs`). `Scene.dayT` (0–1) drives everything:

- **Sky** — gradient stops lerp between day → dusk → night → dawn palettes;
  the sun arcs across the sky (hidden at night), a moon crosses at night,
  stars twinkle, fireflies wander the meadow. Butterflies and sparkles fade
  out after dark.
- **Tint** — a full-stage rect (`#tint`, above `fx`, below the vignette)
  warms the scene at dusk and darkens it at night.
- **Sleep** — at night (`Scene.isNight()`) the owls stay home, eyes droop
  shut, breathing deepens and `z`s float up; the story scheduler (`tryStart`)
  waits out the night and re-checks every 8 s. Manual story keys still work —
  the owls wake for the show. Idle emotes pause while asleep or huddled.
- **Weather** — clear → rain (snow in winter) → rainbow (after rain) →
  clear (`Scene.weather`, `nextWeather`). Rain streaks fall in the `fx`
  layer and ripple the pond; a rainbow arcs behind the hills after the rain.
  While it precipitates (and it's not night), the owls huddle together on
  the branch under a big leaf and squint (`updateRest` in `main.js`).
- **Seasons** — one in-world day per season (`Scene.seasonDays`), rotating
  spring → summer → autumn → winter as `dayT` wraps (`Scene.dayCount`).
  Canopy, hills and grass recolor per season; spring grows blossom and sheds
  pink petals, autumn sheds many orange leaves, winter thins the canopy,
  hides the berries and blankets the ground in snow.

## Interaction

- **Mouse move** — pupils/head track the cursor; cursor hides after 3 s idle
  (screensaver behavior).
- **Click an owl** — hop + "Hoo!" bubble + heart.
- **Click the pond** — splash + ripples.
- **Click the background** — skip the current story.
- **Keys** — `1/2/3` story, `Space` skip, `F` fullscreen, `M` sound.
- **Buttons** — sound toggle (WebAudio, default off), fullscreen.
- Subtle mouse parallax on clouds and hills.

## Sound (tiny, WebAudio, off by default)

Hoot = two descending sine blips; splash = quick square+sine drop; bubble pop =
short triangle blip; wing flap = soft low blip on flight start.

## Verification

`node --check` on every JS file; serve with `python3 -m http.server` and load in
a browser; headless screenshot if a browser is available.
